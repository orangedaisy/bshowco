## Technology

This site is built with [11ty](https://www.11ty.dev/), version controlled with
[Git](https://git-scm.com/) and [GitHub](https://github.com/), and hosted on
[CloudFlare](https://www.cloudflare.com/). I do all my editing with
[NeoVim](https://neovim.io/) in the [Ghostty terminal](https://ghostty.org/).

## Design

Headings are displayed in the lovely [Cooper
revival](https://indestructibletype.com/Cooper/index.html) by [Indestructible
Type*](https://indestructibletype.com/Home.html). I use the swash variant for
page titles. Body copy uses [Atkinson
Hyperlegible](https://www.brailleinstitute.org/freefont/) from Braille
Institute, and code samples are shown in Indestructible Type*'s [Drafting
Mono*](https://indestructibletype.com/Drafting/).

The primary color palette is based on an off-white/ivory (`#f6e7d2`) and navy
(`#123372`). Code samples use the One Dark and One Light themes for Prism.js.
This site responds to your browser's light- or dark-mode preference using the
CSS `light-dark()` function.
